# Как собрать APK

Важно сразу сказать честно: **я не могу скомпилировать готовый .apk прямо здесь**, в этом чате.
Сборка Android-приложения требует Android SDK/NDK (несколько гигабайт),
Java, gradle и обычно 20–40 минут времени — моя песочница для кода этого не
даёт (нет доступа к серверам Google/Android и нет столько времени на сборку).

Зато я подготовил проект так, чтобы вы могли получить APK одним из способов
ниже, ничего не собирая руками вручную.

## Способ 1 (проще всего): собрать в облаке через GitHub Actions

В проекте уже лежит файл `.github/workflows/build-apk.yml`, который сам
скачает Android SDK и соберёт APK на серверах GitHub — бесплатно.

1. Создайте новый репозиторий на https://github.com (можно приватный).
2. Загрузите туда содержимое этой папки (`brawl_arena_mobile`) — например,
   через веб-интерфейс "Add file → Upload files" или через git:
   ```
   git init
   git add .
   git commit -m "Brawl Arena mobile"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/brawl-arena.git
   git push -u origin main
   ```
3. Откройте вкладку **Actions** в репозитории — сборка запустится
   автоматически (или нажмите "Run workflow", если не запустилась сама).
4. Подождите ~20–30 минут (первая сборка самая долгая).
5. Когда сборка завершится зелёной галочкой, откройте её и скачайте файл
   **brawl-arena-apk** внизу страницы — внутри будет готовый `.apk`.
6. Перекиньте `.apk` на телефон (через USB, Telegram, почту и т.п.) и
   установите — заранее разрешите в Android "Установка из неизвестных
   источников".

## Способ 2: собрать локально на Linux / WSL

Работает только на Linux (на Windows — через WSL2 с Ubuntu).

```bash
sudo apt update
sudo apt install -y python3-pip build-essential git zip unzip openjdk-17-jdk \
    autoconf libtool pkg-config zlib1g-dev libncurses5-dev cmake libffi-dev libssl-dev
pip install --upgrade buildozer cython

cd brawl_arena_mobile
buildozer android debug
```

Готовый файл появится в `bin/brawlarena-1.0-arm64-v8a_armeabi-v7a-debug.apk`.
Первая сборка скачивает Android SDK/NDK и может занять 30–60 минут.

## Способ 3: Google Colab (если нет Linux-машины под рукой)

Можно запустить те же команды buildozer в бесплатном блокноте Google Colab
(там уже есть Linux и Python) — загрузите туда папку проекта и выполните
те же команды, что в Способе 2.

## После установки APK

- Разрешение "Установка из неизвестных источников / этого источника"
  Android запросит сам при первом запуске файла — подтвердите.
- Игра запускается в горизонтальной ориентации на весь экран.
- Управление: слева — джойстик движения, справа — джойстик прицела и
  стрельбы (стреляет, когда отклонили от центра). Кнопка "II" в углу —
  пауза, внизу — переключение оружия.

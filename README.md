# Brawl Arena (мобильная версия)

Аркадная «стрелялка-арена» с волнами врагов, укрытиями и 4 видами оружия.
Написана на Kivy/KivyMD, поддерживает и компьютер, и телефон.

Запуск на компьютере: `python main.py` (нужны пакеты `kivy` и `kivymd`).

Как собрать под Android (.apk) — см. файл **КАК_СОБРАТЬ_APK.md**.

## Что изменено для телефона

- На Android/iOS джойстики (движение + прицел/стрельба) включены по
  умолчанию — мышь и клавиатура не нужны.
- Игра запускается в полноэкранном альбомном режиме, без фиксированного
  окна 1280×720 (оно оставлено только для запуска на компьютере).
- Все тексты в интерфейсе переведены на русский язык.
- Добавлены `buildozer.spec` и workflow GitHub Actions для сборки APK.

## Структура

| Файл | Что внутри |
|---|---|
| `main.py` | Точка входа, приложение, определение платформы, сохранение рекорда |
| `settings.py` | **Весь баланс**: герой, оружие, враги, волны, карта |
| `game.py` | Игровое поле: ввод, движение, стрельба, урон, отрисовка |
| `ai.py` | Поведение врагов (машины состояний) |
| `navigation.py` | Поиск пути (поле потока по сетке, алгоритм Дейкстры) |
| `geometry.py` | Столкновения: отрезок-прямоугольник, отрезок-круг, выталкивание |
| `waves.py` | Режиссёр волн: бюджет, шаблоны, отряды, предупреждения |
| `effects.py` | Частицы, взрывы, вспышки, следы, числа урона |
| `entities.py` | Классы героя, врага, пули |
| `ui.py` | Кнопки, окна, джойстик, отрисовка персонажей |
| `screens.py` | Меню и игровой экран (в т.ч. джойстики для телефона) |

## Как менять баланс

- Баланс оружия и врагов: словари `WEAPONS` и `ENEMY_TYPES` в `settings.py`.
- Новые типы волн: `WAVE_TEMPLATES` в `settings.py`.
- Карта: `MAP_LAYOUT` в `settings.py` (сетка путей перестраивается автоматически).
- Новый тип врага: запись в `ENEMY_TYPES` + функция поведения в `ai.py` и
  строка в `BEHAVIOURS`.
